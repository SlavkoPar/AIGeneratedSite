Overview

A tidy layout with a header, a left navigation bar and a footer.

Meridian is a starting point for sites that need clear structure: a header that stays on top, navigation on the left, and a footer that closes the page.

See the features Get in touch

Features

What is included

Sticky header

The header remains visible at the top with the brand, a menu button on small screens and a theme switch.

Left navigation

A sidebar on wide screens that turns into a slide-in drawer on phones and tablets.

Footer

A simple footer with useful links and copyright, always sitting at the bottom of the page.

Accessible

Keyboard friendly, visible focus states, a skip link, and respect for reduced-motion settings.

Light and dark

Follows your system preference and remembers your choice when you switch.

No dependencies

Plain HTML, CSS and JavaScript. Nothing to install and nothing to build.
