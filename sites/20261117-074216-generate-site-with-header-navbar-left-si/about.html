About the layout

A short tour of how the page is put together.

Structure

Each page uses four landmarks: a header, a nav, a main area and a footer. They are arranged with CSS Grid so the header and footer span the full width while the navigation and content share the row between them.

Adding a page

  1. Copy any existing page and rename the file.
  2. Replace what is inside main with your own content.
  3. Add a link to the new page in the left navigation and footer of every page.
  4. Move aria-current="page" to the link that matches the new page.

Changing the look

Colours, the sidebar width and spacing are set as variables at the top of css/style.css. Change them once and every page follows.
