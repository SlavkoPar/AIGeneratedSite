Features

Everything the layout does, on every page.

Responsive

Two columns on wide screens. Below 800 pixels the navigation becomes a slide-in drawer opened from the header.

Keyboard friendly

A skip link, visible focus outlines, and a drawer that closes with the Escape key.

Current page marker

The link for the page you are on is highlighted in the navigation and announced to screen readers.

Sticky footer

The footer stays at the bottom of the window on short pages and follows the content on long ones.

No dependencies

Plain HTML, one stylesheet and one small script. Nothing is loaded from other servers.

Works without scripts

If JavaScript is unavailable, the navigation simply appears below the header instead of in a drawer.
